# RR Challenge

A minimal static landing page, ready to deploy.

## Deploy options

| Platform | Command |
|---|---|
| **Netlify** | Drag the folder into [app.netlify.com/drop](https://app.netlify.com/drop) |
| **Vercel** | `npx vercel` inside this folder |
| **GitHub Pages** | Push to `main`, enable Pages → `/ (root)` |
| **Surge.sh** | `npx surge .` |

## Files
- `index.html` — the landing page
- `Readme.md` — this file
